| Version | Supported          |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Use [GitHub Security Advisories](https://github.com/thekannen/CookDex/security/advisories/new) to report privately.
3. Include steps to reproduce, if possible.

CookDex is maintained by one person in their spare time, so no response time is
promised. Reports are read and taken seriously, and we will work with you to
understand and address the issue before any public disclosure.

Reports are welcome even if you're not sure something is a real problem.
Unless you'd rather stay anonymous, you'll be credited by name in the
advisory, in the release notes for the fix, and in the list below.
